01. Berpikir algoritmik

Sebelum menulis kode, tentukan dulu langkah untuk memecahkan masalah.

KONSEP INTI

Apa itu algoritma?

Algoritma adalah urutan instruksi yang jelas dan terbatas untuk menyelesaikan suatu masalah. Resep memasak adalah analogi sederhana: ada bahan, langkah, dan hasil.

① Input

Data yang masuk, misalnya dua angka.

② Proses

Langkah yang mengolah input.

③ Output

Hasil yang dikeluarkan.

Contoh: jumlah dua angka

INPUT a, b
hasil ← a + b
OUTPUT hasil

Pseudocode adalah cara menuliskan logika dengan bahasa sederhana, tanpa terikat sintaks bahasa tertentu.

Coba sendiri

Ubah nilai input dan ikuti prosesnya.

Output akan muncul di sini.
Ingat: algoritma yang baik harus jelas, punya akhir, dan menghasilkan jawaban yang sesuai untuk input yang valid.

Bayangkan kotak berlabel

nama = "Rani"   # string
umur = 16       # integer
tinggi = 1.62   # float
aktif = True    # boolean

+ - * /

== != > < >= <=

Perbandingan: hasilnya boolean, yaitu True atau False.

and / or / not

%

03. Percabangan

Program dapat memilih tindakan berdasarkan kondisi, seperti persimpangan jalan.

nilai = 82
if nilai >= 75:
    print("Lulus")
else:
    print("Belajar lagi")

Alurnya: periksa kondisi. Jika benar, jalankan blok if; jika salah, jalankan blok else. Python menggunakan indentasi untuk menandai blok.

Ubah nilai dan lihat keputusan

Jika nilai minimal 75, hasilnya Lulus.
Mulai Cek nilai ≥ 75? Ya → Lulus Tidak → Belajar lagi
Gunakan elif jika ada beberapa kemungkinan, misalnya menentukan predikat A, B, C, atau D.

04. Perulangan

Loop menjalankan instruksi berulang kali tanpa perlu menulis kode yang sama berkali-kali.

FOR

Ketika jumlah langkah diketahui

for i in range(1, 6):
    print(i)

range(1, 6) menghasilkan 1 sampai 5. Batas akhirnya tidak ikut dihitung.

WHILE

Selama kondisi benar

energi = 3
while energi > 0:
    print(energi)
    energi -= 1

Kondisi harus akhirnya menjadi salah, atau loop bisa berjalan tanpa henti.

Animasi hitung

05. Fungsi

Fungsi membungkus langkah-langkah dengan nama, sehingga bisa dipakai ulang.

def luas_persegi(panjang):
    return panjang * panjang

hasil = luas_persegi(4)
print(hasil)  # 16

panjang adalah parameter. Angka 4 adalah argumen saat fungsi dipanggil. return mengirimkan hasil kembali ke pemanggil.

Kalkulator luas persegi

Luas = sisi × sisi
Fungsi membuat program lebih terstruktur, mudah diuji, dan mengurangi pengulangan kode.

06. Visualisasi Bubble Sort

Bubble sort membandingkan pasangan angka yang bersebelahan, lalu menukarnya jika urutannya salah.

Siap mengurutkan

Biru = belum berada di posisi akhir. Hijau = posisi sudah dipastikan. Coba amati berapa kali pasangan harus ditukar.

Bagaimana cara kerjanya?

  1. Bandingkan dua angka yang bersebelahan.
  2. Jika angka kiri lebih besar, tukar posisinya.
  3. Geser ke pasangan berikutnya.
  4. Ulangi sampai tidak ada pertukaran yang diperlukan.

Efisiensi

Bubble sort biasanya melakukan pekerjaan sebanding dengan \(n^2\) pada kasus rata-rata dan terburuk. Untuk daftar besar, algoritma seperti merge sort biasanya lebih efisien.

Simulasi ini memakai daftar kecil agar setiap langkah terlihat.

07. Kompleksitas algoritma

Bukan hanya “apakah berhasil?”, tetapi juga “seberapa banyak waktu dan memori yang dibutuhkan?”

O(1)

Konstan

Mengakses elemen array berdasarkan indeks biasanya membutuhkan jumlah langkah konstan.

print(data[0])
O(n)

Linear

Memeriksa setiap elemen satu kali. Jika data dua kali lebih banyak, pekerjaan tumbuh kira-kira dua kali.

for x in data:
    print(x)
O(n²)

Kuadratik

Dua loop bersarang yang masing-masing melewati n elemen dapat menghasilkan sekitar n × n pekerjaan.

for a in data:
    for b in data:
        cek(a, b)
O(log n)

Logaritmik

Pencarian biner membagi ruang pencarian menjadi dua pada setiap langkah, tetapi hanya berlaku jika data sudah terurut dan syaratnya terpenuhi.

tengah = (kiri + kanan) // 2

Bandingkan pertumbuhan langkah

Angka ini ilustrasi jumlah operasi, bukan pengukuran waktu nyata. Notasi Big O menggambarkan laju pertumbuhan saat ukuran input membesar, dengan mengabaikan konstanta dan suku yang lebih kecil.
